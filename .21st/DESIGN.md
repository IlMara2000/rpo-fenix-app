# Fenix Group CRM design

Dark, compact operational workspace using the existing React panels, forms and tables.

Use the unmodified official logo from https://www.grfenix.com/images/logo-small.png and emblem from https://www.grfenix.com/images/logo-white.png. Keep the header and module navigation pinned together. Use collapsible filter panels, readable form grids and full-width nested views. Do not display internal route paths or replace the official brand artwork. Preserve all fields, permissions and form actions.
